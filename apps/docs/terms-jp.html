利用規約

最終更新：2026-11-20

www.ortho-earth.com は、オープンソースのプロジェクトの一部として、Kenji Yoshida が一人で運営しています。サイトを使うことで、この規約に同意したものとします。 個人情報の扱いはプライバシーのページに書いています。

1. 無料で、現状のまま

サイトと地図は無料で使えます。現状のまま提供するもので、いかなる保証もしません。 地図やデータには抜けや古い部分があり得るので、道案内、安全、災害対応、法的な判断のよりどころにはしないでください。 機能は変わったり終わったりすることがあり、サイトが使えない時間もあり得ます。

2. コードとデータ

ソースコードは GPL-3.0（一部のデータ形式のライブラリは MIT）で公開しています。詳しくは README のライセンスの節をご覧ください。 地図データは多くの提供元のもので、それぞれのライセンスに従います。出典は各地図に表示しています。

3. アップロードするファイルと作品

  • アップロードしたものの権利は、あなたに残ります。共有する権利のあるものだけをアップロードしてください。
  • 違法なもの、他人の権利を侵すもの、他人やサービスを害する目的のものはアップロードしないでください。
  • 公開した作品は、題名・リンク・作者名・説明・サムネイルをだれでも見られます。
  • この決まりに反するものは削除し、アカウントを停止することがあります。
  • 手元にも必ずコピーを残してください。保存したファイルはバックアップの代わりにはなりません。

4. サービスの適切な利用

自動化したアクセスでサイトやサーバー（AI エージェント向けの MCP サーバーを含みます）に過剰な負荷をかけたり、制限や安全のしくみをすり抜けようとしたりしないでください。 セキュリティの問題の報告は SECURITY.ja.md をご覧ください。

5. 変更とお問い合わせ

規約を変えるときは、このページを更新し、上の日付を変えます。この規約は日本法に従います。 お問い合わせは kenji.yoshida.home.2026@gmail.com へどうぞ。
