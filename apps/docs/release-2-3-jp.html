Ortho Earth 2.3 を公開しました

ホップ・ステップ・ジャンプ

2026-11-02 · Kenji Yoshida · @ortho-earth/globe · @ortho-earth/core · @ortho-earth/cesium

@ortho-earth/globe と @ortho-earth/core を 2.3 にしました。この十日あまりの三つの版は、ちょうどホップ・ステップ・ジャンプになりました。

版したこと
ホップ　2.1（10 月 23 日）MapLibre の版
ステップ　2.2（10 月 31 日）CesiumJS の版
ジャンプ　2.3（11 月 2 日）両方にもう一歩、そしてどちらにも無い描画

1. Cesium と MapLibre にもう一歩

本物と同じコードを動かして絵を比べる物差しで、Cesium の Sandcastle（303 本）は同じ絵が 190 本から 226 本に、 MapLibre の公式例（137 本）は同じ絵が 85 本から 91 本に、一部しか動かない例が 12 本から 3 本になりました。 全部の組は /sandcastle と /maplibre で見られます。

2. 新しい描画

map.setPostChain に、Cesium にも MapLibre にも無い六つの効果が加わりました（WebGPU だけ）。 どれもエンジンが前から持っていた深度と法線を使い回したもので、SSR が約 380 行、残りの五つで約 720 行、それぞれ 1 日で入りました。 

map.setPostChain([{ type: "ssr" }]);
// ほかに contactShadow・heightFog・godRays・rain・toon

3. 使い方は 2.2 のまま

2.2 向けのコードはそのまま動きます。あわせて @ortho-earth/cesium 0.2.0（globe 2.3 以上が要ります）と @ortho-earth/voxel 0.6.1 を出します。 

npm i @ortho-earth/globe@2.3

振り返ると、2.2 で書いた式「MapLibre × Cesium − メルカトル ＋ α」で、いちばん効いていたのは「− メルカトル」だったのかもしれません。 地図を最初から球の上に描いてきたので、MapLibre の 2D の例も Cesium の 3D の例も、同じ一つの描き方で受け止められました。2D と 3D を別々に作ってつなぐのではなく、メルカトルを捨てたこと。 それが 2D と 3D の統合の本質だったと思います。2.3 では、その上に ＋ α を初めて具体的に足しました。

この三日間の詳しい記録は「V.2.3.0 二柱の神のあいだで」に。
