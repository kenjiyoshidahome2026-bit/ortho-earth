Ortho Earth 2.2 を公開しました

CesiumJS の例が地球儀で動き、Leaflet と Google Maps のコードも付いてきた

2026-10-31 · Kenji Yoshida · @ortho-earth/globe · @ortho-earth/core · @ortho-earth/cesium

@ortho-earth/globe と @ortho-earth/core を 2.2 にしました。 2.1 は MapLibre の版でした。この版は CesiumJS の版です。目標は、Cesium にできて Ortho Earth にできないものを無くすことでした。 新しいパッケージは三つです。@ortho-earth/cesium と、同じ考え方の @ortho-earth/leaflet・@ortho-earth/gmaps です。

1. CesiumJS のコードを地球儀で

@ortho-earth/cesium は、CesiumJS 1.146 と同じ名前の名前空間を返します。描かない部分（計算、時刻、カメラ、Entity、CZML、時計、ion、ウィジェット）は Cesium のコードそのままで、 描くところだけが Ortho Earth の地球儀です。だから Cesium のコードは import を変えるだけで動きます。 

import * as Cesium from "@ortho-earth/cesium";
const viewer = new Cesium.Viewer("cesiumContainer");

物差しは Cesium 公式の Sandcastle 309 本です。一本ずつ、本物の CesiumJS と地球儀でコードを変えずに動かし、同じ時刻・同じカメラで撮った二枚の絵を比べます （採点は 297 本。月・火星、ビューアの無い例、2D で始まる例は外しています）。全部の組は /sandcastle で見られます。

1　動く1290

採点した例はすべて動き、Cesium と同じ答えを返すようになりました。およそ三分の二は同じ絵です。最後の撮影は、npm に出したのと同じコードを、実 GPU（WebGPU）で撮ったものです。 そこまでの間にエンジン自身も多くを覚えました。どれも素の地球儀の API からも使えます。

  • 太陽・HDR・環境光による模型の光、影、clearcoat や KTX2 テクスチャなどの glTF の機能。
  • 画面の効果（ブルーム、シルエット、被写界深度、レンズフレア、自分の GLSL の stage）、粒子、雲、束ね表示。
  • 地形の塗り（標高の段彩、等高線、傾斜）、海の深さ、半透明の地球、地下に潜れるカメラ。
  • 平面と多角形による 3D Tiles の切り抜き、3D Tiles への画像の貼り付け、I3S、点群とボクセル、Gaussian splat、CustomShader（WebGL2 では GLSL のまま、WebGPU では WGSL に訳して）。

地球儀そのものの API に移りたいときは、CesiumJS から来た人へ に Cesium の呼び出しと対応する書き方を並べています。

2. Leaflet と Google Maps のコードも

同じやり方で、ほかの二つの API も動くようになりました。@ortho-earth/leaflet は Leaflet 1.9 と同じ形の L を、@ortho-earth/gmaps は google.maps を返します。 どちらも地球儀の上に（望めば平らな MapLibre の地図に）描き、変えるのは import だけです。Google の方は、地図に Google の鍵が要りません。 鍵を渡せば、Geocoder・Directions・Places・Street View を Google のサービスへ中継します。

どちらにもまだ公式の例のギャラリーは無いので、Leaflet から来た人へ と Google マップから来た人へ に、訳すものを正確に並べました。 訳さないものは、コードを動かせばコンソールに出ます。

3. 使い方は 2.1 のまま

2.2 はすべて上に足した物です。2.1 向けに書いたコードは 2.2 でそのまま動きます。 

npm i @ortho-earth/globe@2.2
npm i @ortho-earth/cesium      # CesiumJS のコード
npm i @ortho-earth/leaflet     # Leaflet のコード
npm i @ortho-earth/gmaps       # Google Maps のコード

並べてみると、一つの式に見えてきました：Ortho Earth ＝ MapLibre × Cesium − メルカトル ＋ α。
