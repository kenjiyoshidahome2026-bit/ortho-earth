Ortho Earth 2.0 を公開しました

TypeScript になり、公開の口を整えた大版
2026-10-17 · @ortho-earth/globe · @ortho-earth/core · @ortho-earth/japan · geopbf

地球儀の地図エンジン @ortho-earth/globe と、それを支えるパッケージを 2.0 にしました。 2.0 は、ライブラリを TypeScript に移したのに合わせて、1.x が互換のために残していた別名・古い口・内部への入口を外す大版です。 地図の描き方や API の大半は 1.x と同じで、多くのコードは import もそのままで動きます。

1. 何が変わったか

  • ソースは TypeScript（strict）。型は源から作ります。1.x の手書きの型と実体のずれ（型にあって実体に無い名前、その逆）は、実体に合わせて直しました。import の書き方は変わりません。
  • 公開の口は名前を挙げたものだけ。1.x は src/ の全ファイルを読めましたが、2.0 は各パッケージの package.json の exports に並ぶサブパスだけを出します。internal/* は閉じました。
  • 1.x の別名を外した。plateau は mesh に、maxPitch は常に度（MapLibre と同じ）に、addCOPC は addPointCloud に。自作ガジェットは map.registry.gadgets.add(name, (map, ...args) => handle) で登録し、本体は map を第 1 引数で受けます。
  • 新しいパッケージ。React の部品 @ortho-earth/react、Google の写実 3D Tiles @ortho-earth/google-tiles、KTX2 のテクスチャ @ortho-earth/ktx2、大量の模型・看板・3D の文字の @ortho-earth/plugin-scene、Gaussian splat の @ortho-earth/plugin-splat を初めて公開しました。

2. 入れ方

npm i @ortho-earth/globe

latest は 2.0 です。最初の地図の出し方は Get started に、MapLibre GL JS や CesiumJS のコードから移る道は MapLibre から・CesiumJS から にあります。

3. 1.x から移る・1.x を使い続ける

書き換えが要る所は、パッケージごとに「1.x の書き方 → 2.0 の書き方」の表にまとめました： MIGRATION.md（1.x から 2.0 への移行）。表に無い API は 1.x と同じです。

1.x のままでいたい場合

版の範囲で指定します：npm i @ortho-earth/globe@1（geopbf なら geopbf@1）。 1.x のソースは GitHub のブランチ v1 に残してあります。 配った URL や QR を壊さないため、URL の互換（l= のローマ字キー、lang=jp など）は 2.0 でも読み続けます。

4. 2.0.2 までの直し

2.0.0 の公開の後、使って見つかった所を直しています。2.0.2（2026-10-19）の主な直し：

  • worker の中で @loaders.gl 4.5 と組むと b3dm の 3D Tiles を描けなかった所を直しました。
  • 世界の塗りや標高の索引を切った地図では、それらを取りに行かないようにしました。
  • 起動時の描き直しを束ね、3D Tiles は兄弟のタイルが揃ってから塊で出すようにしました。描画 worker の空回りも止めました。

3D の建物を表示する速さは、MapLibre GL JS（deck.gl）・CesiumJS・Navara・TerriaJS と同じ条件で比べた記事を準備しています。出たら 記事の一覧 に足します。
