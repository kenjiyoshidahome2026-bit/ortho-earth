Coming from CesiumJS

The same things, written with Ortho Earth
3D Tiles · I3S · quantized-mesh terrain · glTF/GLB · WGS84 ellipsoid · CZML · the clock

Ortho Earth is a 3D globe map engine for the browser (WebGPU with a WebGL2 fallback) whose API follows MapLibre GL JS. Many of the things you do in CesiumJS have a counterpart here. This page lists them side by side: what you write in CesiumJS, what you write in Ortho Earth, and a page where you can see it running. All examples assume const map = await createGlobe({ target: "#map" }) from npm i @ortho-earth/globe.

What works differently

  • The API is MapLibre-shaped. Sources and layers, style.json, setPaintProperty and queryRenderedFeatures work as in MapLibre GL JS. If you also know MapLibre, see From MapLibre GL JS.
  • Drawing happens in a worker. The map is drawn on an OffscreenCanvas in a render worker, so your own drawing joins through map.overlay(module), map.addThree() or a custom layer with a url.
  • No server, no account. The engine reads public data directly; there is no token unless the data you read needs one.
  • The flat world map is Equal Earth, not Web Mercator. See Equal Earth on the GPU.

The full list of methods is in the package's type definitions (@ortho-earth/globe/globe.d.ts) and the engine overview. Step-by-step setup is in Build with Ortho Earth.
