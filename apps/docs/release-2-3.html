Ortho Earth 2.3 is out

Hop, step, jump

2026-11-02 · Kenji Yoshida · @ortho-earth/globe · @ortho-earth/core · @ortho-earth/cesium

@ortho-earth/globe and @ortho-earth/core are now 2.3. The three releases of the last ten days or so make a hop, a step and a jump.

ReleaseWhat it did
Hop　2.1 (Oct 23)The MapLibre release
Step　2.2 (Oct 31)The CesiumJS release
Jump　2.3 (Nov 2)One more step toward both, and rendering neither has

1. One more step toward Cesium and MapLibre

Measured by running the same code as the real thing and comparing pictures: on Cesium's Sandcastle (303 examples) the same picture went from 190 to 226, and on MapLibre's official examples (137) the same picture went from 85 to 91, while those that only partly run went from 12 to 3. Every pair is at /sandcastle and /maplibre.

2. New rendering

map.setPostChain gains six effects that neither Cesium nor MapLibre has (WebGPU only). They all reuse the depth and normals the engine already had: SSR is about 380 lines and the other five about 720, and each went in within a day. 

map.setPostChain([{ type: "ssr" }]);
// also contactShadow, heightFog, godRays, rain, toon

3. Same API as 2.2

Code written for 2.2 runs as is. Also out: @ortho-earth/cesium 0.2.0 (needs globe 2.3 or later) and @ortho-earth/voxel 0.6.1. 

npm i @ortho-earth/globe@2.3

Looking back at the formula from 2.2, MapLibre × Cesium − Mercator + α, the term that mattered most may have been − Mercator. Because the map was drawn on a sphere from the start, MapLibre's 2D examples and Cesium's 3D examples could both be taken in by one way of drawing. Not building 2D and 3D separately and joining them, but dropping Mercator: I think that was the essence of bringing 2D and 3D together. 2.3 is the first release to put something concrete into the + α.

The detailed record of these three days is in "V.2.3.0 Between two gods".
