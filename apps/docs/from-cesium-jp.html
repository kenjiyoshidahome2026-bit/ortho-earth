CesiumJS から来た人へ

同じことを Ortho Earth で書く
3D Tiles · I3S · quantized-mesh の地形 · glTF/GLB · WGS84 楕円体 · CZML · 時計

Ortho Earth はブラウザで動く 3D 地球儀の地図エンジン（WebGPU、無ければ WebGL2）で、API は MapLibre GL JS に合わせています。 CesiumJS でしていることの多くに、ここでの書き方があります。この頁はそれを並べたものです：CesiumJS での書き方、Ortho Earth での書き方、動いている頁。 例はどれも npm i @ortho-earth/globe のあと const map = await createGlobe({ target: "#map" }) とした前提です。

違う所

  • API は MapLibre の形です。source と layer・style.json・setPaintProperty・queryRenderedFeatures は MapLibre GL JS と同じ書き方です。MapLibre も使っているなら MapLibre GL JS のコードを球へ を見てください。
  • 描くのは worker です。地図は描画 worker の OffscreenCanvas に描かれます。自分の描画は map.overlay(module)・map.addThree()・url を持つ custom layer で加わります。
  • サーバーもアカウントも要りません。エンジンは公開データを直接読みます。読むデータが求めない限り、鍵は要りません。
  • 平らな世界図は Equal Earth です（Web メルカトルではない）。Equal Earth 図法を GPU で描く を見てください。

全ての口はパッケージの型定義（@ortho-earth/globe/globe.d.ts）と エンジンの概要 にあります。 手順は Build with Ortho Earth（英語）にあります。
