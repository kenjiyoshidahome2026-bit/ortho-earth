1. What is altpbf?

altpbf is a binary raster elevation tile format built on Protocol Buffers. Where GeoPBF handles vector geometry (coastlines, roads, polygons), altpbf handles raster elevation grids — the digital elevation model (DEM) and bathymetry data needed for terrain rendering, shadow calculation, and 3D visualization.

Each tile is a rectangular grid of Int16 elevation values (meters), delta-encoded and compressed with deflateRaw. Three tile sizes cover the globe at different resolutions, and the ortho-earth engine selects the appropriate tier automatically based on zoom level.

The altpbf npm package (1.2.0) is the format only: encode, decode, encodeName / decodeName and altpbf2png. It is written in TypeScript (strict) and ships type definitions (AltpbfTile, AltpbfDecoded, AltpbfSource, Altpbf2PngOptions, …). Its only runtime dependency is geopbf; it needs CompressionStream, and altpbf2png also needs OffscreenCanvas. Fetching, caching, worker decoding and height lookup (createGetHeight, createTileLoader) live in the engine, @ortho-earth/core/elevation.

Why Int16?

Earth's elevation range is roughly −11,000 m (Mariana Trench) to +8,849 m (Everest). A signed 16-bit integer covers −32,768 to +32,767 m — exactly enough, with no wasted bits. Compared to Float32, Int16 halves the data size before any compression is applied.

GEBCO provides global coverage including ocean bathymetry, making it the baseline for all zoom levels. ALOS AW3D30 is a high-precision land-only DEM published by JAXA, used for close-up terrain rendering where its 30 m resolution delivers visually meaningful detail. Since ALOS tiles only exist for land areas, the engine keeps an index of available tiles and falls back gracefully to GEBCO HGT10 for ocean queries. In Japan, HGT01 tiles are re-baked from GSI DEM10B (bare-earth DTM, where AW3D30 is a surface model) and stored in the bucket; the engine reads the bucket first and only falls back to JAXA when no baked tile exists.

3. 3-Tier Tile Hierarchy

altpbf defines three tile sizes, each covering a different angular extent of the globe. createGetHeight (@ortho-earth/core/elevation) switches between tiers based on the current zoom level, defaulting to level1 = 7 and level2 = 12.

Each tier is a strict fallback chain: HGT01 → HGT10 → HGT90. If a high-resolution tile is unavailable (ocean, no ALOS data) or returns no elevation, the next coarser tier answers the query transparently. The caller always receives a valid elevation value.

Bilinear Interpolation

Within each tile, calcHeight(x, y, v) performs bilinear interpolation across the four nearest grid cells — no staircase artifacts. Normalized coordinates (0–1) within the tile are computed from the raw lat/lng and passed directly to the interpolation function.

4.1 Delta Encoding for Elevation

Terrain elevation changes gradually — neighboring cells in a DEM rarely differ by more than a few tens of metres. Delta encoding exploits this locality: storing differences rather than absolute values keeps numbers small, and small numbers encode to fewer Varint bytes.

After delta encoding, most values in a smooth terrain tile fit in a single Varint byte. Combined with deflateRaw on top, altpbf tiles are typically 5–15× smaller than an equivalent raw Int16 array.

decode reads the packed SVarint body straight into the output Int16Array — no intermediate JS arrays — using a small embedded WebAssembly kernel (SIMD128 where available, scalar wasm otherwise) with a plain-JS fallback when wasm is unavailable (e.g. blocked by CSP). A 5.7M-point HGT10 tile decodes in ~21 ms / +12 MB instead of ~99 ms / +230 MB with the previous implementation.

5. Tile Naming

Each tile is uniquely identified by a compact name string encoding its range, latitude, and longitude: 

encodeName(lng, lat, range)
// range > 0  →  "R{02d(range)}{lat_prefix}{03d(|lat|)}{lng_prefix}{03d(|lng|)}"
// range omitted / 0  →  "{lat_prefix}{03d(|lat|)}{lng_prefix}{03d(|lng|)}"  (key of the JAXA AW3D30 index)
// (lng, lat) is the tile's bottom-left (south-west) corner; decodeName(name) → [lng, lat, range]

// Examples:
encodeName(0, -90, 90)  // → "R90S090E000"  (HGT90 quadrant 0–90°E · 0–90°S)
encodeName(130, 30, 10)  // → "R10N030E130"  (HGT10 Japan region)
encodeName(135, 35, 1)   // → "R01N035E135"  (HGT01, Kinki region)
encodeName(135, 35)      // →    "N035E135"  (AW3D30 index key)
decodeName("R01N035E135")   // → [135, 35, 1]
ALOS Tile Existence Check

ALOS AW3D30 tiles exist only over land. Before requesting an HGT01 tile, the engine checks an in-memory index loaded from the JAXA tile list (index_alos() in @ortho-earth/core/elevation, cached in IndexedDB). Ocean queries immediately fall back to HGT10 without a network round-trip. If JAXA is unreachable, the engine continues with an empty index and refetches it in the background.

// packages/ortho-core/src/elevation/worker.ts — zero-copy Int16Array transfer to main thread
import { load, setApiUrl } from "./loader.ts";
onmessage = async e => {
	const { name, apiUrl } = e.data;
	if (apiUrl) setApiUrl(apiUrl);
	try { const obj = await load(name);
		obj ? postMessage(obj, [obj.data.buffer])  // ← Transferable: zero-copy
			: postMessage(null);
	} catch (e) { postMessage(null); }
};

The worker inflates and decodes the tile off-main-thread, then transfers the Int16Array buffer back via the Transferable interface — no copying, no serialization. The worker runs under the engine's "ortho:height" worker role. createGetHeight uses a single worker that handles requests one at a time; while a load is in flight, render-side queries return 0 until it arrives, and { wait: true } callers wait for it. createTileLoader (used by the terrain atlas) runs a pool of up to 3 workers, merges concurrent requests for the same tile, and decodes in-thread when nested workers are unavailable. Once decoded, tiles are persisted to IndexedDB for instant re-use across sessions.

7. GEBCO Processing Pipeline

The raw GEBCO source is a set of GeoTIFFs at 21,600 × 21,600 pixels per 90° quadrant (eight quadrants, 86,400 × 43,200 for the globe). The uploader app's GEBCO() function (apps/uploader/src/terrain/gebco.js, not part of the altpbf package) downloads and tiles it into altpbf format: 

// Step 1 — HGT90: 8× average-pool downsampling
// 21600 × 21600 → 2700 × 2700  (one 90° tile per quadrant)
// Each output pixel = mean of 8×8 source pixels

// Step 2 — HGT10: extract 9×9 = 81 sub-tiles per quadrant (2400 px tall)
// Apply polar width shrink so tiles remain square on-screen
// shrink(lat): fraction of full-width actually used at that latitude

8. API Reference

// ── altpbf (npm) — the format ───────────────────────────
import { encode, decode, encodeName, decodeName, altpbf2png } from "altpbf";
import type { AltpbfTile, AltpbfDecoded, AltpbfSource, AltpbfColorMap, Altpbf2PngOptions } from "altpbf";

// ── createGetHeight — engine entry point (@ortho-earth/core/elevation) ──
import { createGetHeight } from "@ortho-earth/core/elevation";
const getHeight = await createGetHeight({
	apiUrl:  'https://your-api.example.com',  // nativeBucket base URL
	level1:  7,    // zoom threshold HGT90 → HGT10
	level2:  12,   // zoom threshold HGT10 → HGT01
	onstart: name => console.log(`loading ${name}...`),
	onend:   name => console.log(`done ${name}`),
});

// Query elevation at any (lng, lat, zoom)
const h = await getHeight(139.77, 35.68, 14);  // → height in metres

// Zoom omitted → always use highest resolution (HGT01)
const h = await getHeight(139.77, 35.68);

// ── altpbf2png — render tile as PNG ────────────────────
const blob = await altpbf2png(pbfBlob, {
	size:     256,         // output PNG size (square)
	colorMap: h => [r, g, b] // custom color function (optional)
});

// ── Low-level encode / decode ───────────────────────────
const buf = await encode({ name, source, lng, lat, range, width, height, data });  // → Uint8Array
const obj = await decode(blob);  // → { name, source, lng, lat, range, width, height, data: Int16Array }

// ── GEBCO bulk tile generation (apps/uploader) ─────────
await GEBCO({ year: 2026, noIce: false, log: console });
// Downloads ~12 GB source, generates HGT90 + HGT10 altpbf tiles, uploads to bucket
