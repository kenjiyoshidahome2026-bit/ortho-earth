プライバシー

www.ortho-earth.com が集める情報と、その理由です。最終更新：2026-11-20

Ortho Earth は、Kenji Yoshida が一人で運営しているオープンソースのプロジェクトです。サイトの地図はすべて、アカウントなしで使えます。 広告は出さず、データを売ることもなく、広告や追跡のための Cookie も使いません。

1. 訪問の集計

サイトは Cloudflare を通して配信していて、Cloudflare の Web Analytics がページに組み込まれます。 これは Cookie を使わずに、ページの表示回数、どのページから来たか、国、ブラウザや端末の種類を数えるものです。 どのページが読まれているかを知るために、この合計だけを見ています。また、ほかのホスティングと同じく、Cloudflare はページを届けたり攻撃を防いだりするために IP アドレスを扱います。 詳しくは Cloudflare のプライバシーポリシーをご覧ください。

2. ログイン（任意）

一部のアプリでは、GitHub・Google・X でログインして、ご自身のファイルを保存したり作品を公開したりできます。そのときだけ、次の情報を保存します。

  • そのサービスでのアカウント ID、表示名、プロフィール画像、（サービスから渡される場合は）メールアドレス
  • ログイン状態：ブラウザの Cookie に入れるランダムな ID（30日間）。サーバー側には、その ID を変換した値と、ブラウザの種類を示す文字列だけを残します
  • アップロードしたファイル（1人あたり最大1GB）と、公開した作品。公開した作品（題名・リンク・作者名・説明・サムネイル）は、その性質上だれでも見られます

これらは Cloudflare（D1 データベースと R2 ストレージ）に保存し、この機能を動かすためだけに使います。ファイルと作品は、いつでもご自身で削除できます。 アカウントごと消したい場合は、どのサービスでログインしたかを添えて kenji.yoshida.home.2026@gmail.com へご連絡ください。

3. ブラウザの中だけに残るデータ

表示を速くするために、地図は読み込んだタイルをブラウザの保存領域に置き、端末が WebGPU を使えるかどうかなどの小さな設定を覚えます。 これは端末の中にだけあり、サイトに送られることはありません。ブラウザでこのサイトのデータを消去すれば消えます。

4. ほかのサービスから読み込む地図データ

一部の地図は、公開データの提供元から直接データを読み込みます（地図タイル、衛星や地震の情報、PLATEAU の3D都市モデル、国土地理院のデータなど）。 そのときブラウザはそれらのサービスに接続し、各サービスは自身の方針のもとで IP アドレスを扱います。

5. AI エージェント向けの MCP サーバー

www.ortho-earth.com/mcp のサーバーは、Ortho Earth についての読み取り専用の質問に答えるだけです。質問の内容は保存しません。

6. 変更とお問い合わせ

内容が変わるときは、このページを更新し、上の日付を変えます。お問い合わせは kenji.yoshida.home.2026@gmail.com へどうぞ。
