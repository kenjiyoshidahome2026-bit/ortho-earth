Run it yourself. This is the example's HTML with only two paths changed: the MapLibre module import is now @ortho-earth/globe/maplibre, and the CSS comes from unpkg. Save it as index.html in a Vite project that has @ortho-earth/globe installed (Get started, Route A), then npm run dev. The engine's workers must come from your own origin, so a bare CDN import does not work. Run above plays this very source right here.
