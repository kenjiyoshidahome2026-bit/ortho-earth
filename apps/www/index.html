Data format · MIT GeoPBF A Protocol Buffers geospatial binary format extending GeoJSON — about 1/10 the size, with bidirectional converters to common GIS formats. Can even carry icons. Overview 日本語
Elevation · MIT AltPBF Protocol Buffers raster elevation tiles — 3-tier zoom LOD, GEBCO + ALOS sources, Int16 delta with deflate, zero-copy worker transfer for high-throughput terrain. Overview 日本語
Renderer · GPL-3.0 OrthoMap A WebGL framework for the orthographic globe — composites base map, vector (Gint) and terrain through a worker pipeline. Reads GeoPBF / AltPBF natively. Overview 日本語
Vector engine · GPL-3.0 Gint Geographic Interleaved Binary — a 64-bit format pairing Morton spatial indexing with Visvalingam–Whyatt LOD weighting. GPU Culling and Stencil Tessellation, straight on the GPU. Overview 日本語 Interactive demos Morton Order GPU Culling Stencil Tessellation
