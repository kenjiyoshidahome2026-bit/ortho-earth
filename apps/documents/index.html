Renderer
Gint ortho-map · GPL-3.0

Geographic Interleaved Binary Format — 64-bit Morton-encoded spatial indexing with Visvalingam–Whyatt LOD weighting. GPU-accelerated WebGL renderer featuring stencil-based polygon fill, dynamic level-of-detail pipeline, and constellation-aware sky rendering.

Data Formats
GeoPBF geopbf · MIT

Protocol Buffers-based geospatial binary format. Lightweight, universal converter, ArrayBuffer-native — the wire format for browser GIS. Self-contained FlatBuffers implementation with all attributes as string type.

AltPBF altpbf · MIT

Protocol Buffers-based raster elevation tiles. 3-tier zoom LOD, GEBCO + ALOS dual sources, Int16 delta encoding with deflateRaw compression. Worker zero-copy transfer for high-throughput terrain rendering.
