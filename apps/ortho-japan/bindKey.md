# キーバインド一覧（ortho-japan）

`ctrl(⌘)` は Ctrl / ⌘ のどちらでも可（Mac は ⌘・その他は Ctrl）。
すべて入力欄（検索など）にフォーカスがある間は無効＝そちらの文字入力を邪魔しない。

## カメラ操作（押しっぱなしで連続）

| キー | 動作 |
|---|---|
| ↑ ↓ ← → | パン |
| shift + ↑↓ | ズーム |
| shift + ←→ | 回転（画面中心を軸に） |
| ctrl(⌘) + ↑↓ | チルト（↑=起こす／↓=倒す） |

## 単発アクション

| キー | 動作 |
|---|---|
| ctrl(⌘) + j | 日本全体へ |
| ctrl(⌘) + z | 全画面表示 |
| ctrl(⌘) + @ | 現在地（GPS） |
| ctrl(⌘) + s | 画面を画像で保存（screenshot） |
| ctrl(⌘) + p | 印刷（平面図） |
| ctrl(⌘) + shift + p | 建物3D（PLATEAU）データ管理 |
| n | 北向き・水平へリセット |
| m | 距離・面積の計測 |
| ? | 操作説明カードの開閉 |
| / | 検索窓へフォーカス |

### 修飾なしにした理由（n / m / ? ）

当初 `ctrl(⌘)+n / +m / +h` を想定したが、macOS がこれらを OS レベルで奪う
（⌘N=新規ウィンドウ・⌘M=最小化・⌘H=アプリを隠す）ため JS で横取りできない。
そこで北向き=`n`・計測=`m`・操作説明=`?` を修飾なしに変更した。
