# キーバインド一覧（ortho-japan）

`ctrl(⌘)` は Ctrl / ⌘ のどちらでも可（Mac は ⌘・その他は Ctrl）。
すべて入力欄（検索など）にフォーカスがある間は無効＝そちらの文字入力を邪魔しない。

## カメラ操作（押しっぱなしで連続）

| キー | 動作 |
|---|---|
| ↑ ↓ ← → | パン |
| shift + ↑↓ | ズーム（マウス位置を軸に・無ければ画面中心） |
| shift + ←→ | 回転（マウス位置を軸に・無ければ画面中心） |
| ctrl(⌘) + ↑↓ | チルト（↑=起こす／↓=倒す） |

## 単発アクション

| キー | 動作 |
|---|---|
| j | 日本全体へ |
| @ | 現在地（GPS） |
| n | 北向き・水平へリセット |
| m | 距離・面積の計測 |
| ? | 操作説明カードの開閉 |
| / | 検索窓へフォーカス |
| ctrl(⌘) + z | 全画面表示 |
| ctrl(⌘) + s | 画面を画像で保存（screenshot） |
| ctrl(⌘) + p | 印刷（平面図） |
| ctrl(⌘) + shift + p | 建物3D（PLATEAU）データ管理 |
| Esc | 開いている物を閉じる（優先順に：計測中→確定/消去・印刷/PLATEAUモーダル→閉じる・右クリックメニュー→閉じる・埋め込み地図→閉じる） |

`Esc` は「今いちばん手前で開いている物」を一つ閉じる係。何も開いていなければ埋め込み用の閉じる（`ortho:close`）だけが反応する。

### 修飾なしにした理由（n / m / ? ほか）

当初 `ctrl(⌘)+n / +m / +h` を想定したが、macOS がこれらを OS レベルで奪う
（⌘N=新規ウィンドウ・⌘M=最小化・⌘H=アプリを隠す）ため JS で横取りできない。
北向き=`n`・計測=`m`・操作説明=`?` を修飾なしにし、日本=`j`・現在地=`@` も
修飾なしへ揃えた。全画面/保存/印刷/PLATEAU はブラウザ標準（⌘Z/S/P）を
preventDefault で横取りできるので `ctrl(⌘)` 付きのまま。

## UI の振る舞い

- 左上・右上のアイコンは、マウスを動かすと表示・止まると暫くして（約2.5秒）フェードアウト。
  触れている間・検索を開いている間は消えない。タッチ端末では常時表示（対象外）。
- `/` は検索窓が畳んでいれば展開してからフォーカスする。
- ショートカット（矢印・単発キー）は「文字入力系にフォーカス中（入力欄・プルダウン `<select>`・編集領域）」か
  「モーダルが開いている（印刷・PLATEAU・右クリックメニュー）」間は無効＝背後の地図/ガジェットへ漏れない。
  この判定は `gadgets/keys.js`（矢印は `ortho-core` の `isTypingTarget` と共有）に一元化。
