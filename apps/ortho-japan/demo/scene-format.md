# scenes — 共有シーン・フォーマット v2（demo 同型）

> permalink の視点を数珠つなぎに、字幕とともに**ライブ再生**する JSON。動画ではない＝実秒でエンジンが毎フレーム描く（軽い・止めて回せる・端末で尺が伸縮しても崩れない）。
> **ドロップ**または **`?scene=<URL>`** で再生。**行の書式は組み込みデモ台本（demo/scenes.js）と完全に同一**＝一つの書式（v2・2026-08-08 統一）。
> v1（`type:"sceneCollection"`・`.scene.json`・transition/defaults・hold:0 連続規約・camera.keys・秒⇄ms 混在）は**廃止**（クリーンブレーク・未公開のうちに）。
> キーは汎用名＝**書式に固有名詞を入れない**（Plateau 等は説明にだけ現れる）。時間は**全部「秒」**（hold / slideHold / travel）。

## 0. 拡張子・見分け（drop routing）
- **拡張子** ＝ `.scenes`（単一サフィックス）。中身は素の JSON（`JSON.parse` がそのまま効く）。
- **gzip も受ける**＝`.scenes.gz`、または `.scenes` のまま gzip した中身。判定は拡張子でなく**中身の gzip 印（1f 8b）**＝ブラウザ標準 `DecompressionStream` で解凍（依存ゼロ）。`?scene=` も同様（サーバが Content-Encoding で解く場合は素通り）。
- **見分けの権威は中身の `"type":"scenes"`**：`.scenes`(.gz) は確定／`.json`・`.geojson` は先頭64KBに `"type":"scenes"` を含めば全 parse、無ければ従来 geopbf（`FeatureCollection`）。
- MIME は判定に使わない（`file.type` は不定）。`?scene=` も同じ type 判定（fetch→`type:"scenes"` でなければ再生しない）。
- **`?scene=` の門は `?g=` と共用**（2026-09-04）：https 限定（開発時のみ localhost の http 可）・`gh:user/repo[@ref]/path` 短縮形→GitHub raw・credentials 無し・8MB 上限。台本の `title`/言語兄弟/視点文字列は**表示前に消毒**（他人作の台本を当ドメインで再生する前提＝目次・行・字幕のどこにも生 HTML は入らない）。

## 1. 構造（平ら）
```jsonc
{
  "type": "scenes",             // 必須・見分け
  "title": "隅田川を遡る",
  "frame": "16:9",              // 任意：画面の定義（作品の画角＝エディタ用メタ・"16:9"/"9:16"/"1:1"/"4:3"、"free"＝枠なし）。プレーヤーは無視＝ライブ再生はどの画面でも成立
  "waitLoading": true,          // 任意：重いデータ（3D都市）が立ち上がるまで開始を待つ（リビールが必ず街に着地・道中のポップイン無し）
  "hold": 4,                    // 任意：静止秒の台本既定（scene 再生の既定＝3。▶デモは5.5＝発表の間合いは別）
  "slideHold": 4,               // 任意：幕（スライド）の表示秒の台本既定（プレーヤー既定 4）
  "mobile": -1.2,               // 任意：縦長画面の Δz 台本既定
  "preload": ["中央区", "…"],   // 任意：明示先読みリスト（カタログ名・無指定＝視点から自動導出）
  "scenes": [ … ]               // ← 行の配列（これが本体・demo/scenes.js と同じ書式）
}
```

## 2. scenes[]（行の書式＝demo と同一）
| key | 意味 | 既定 |
|---|---|---|
| `view` | 到達視点＝permalink ハッシュ `#z/lat/lng[/Pt][/Br][/l=…][/c=…]`。遷移は球面フライト（地図遷移・尺は自動） | いずれか必須 |
| `glide` | `view` の代わり＝滑走（移動）。`travel` 指定＝尺どおりの同時補間／省略＝位置→方位→チルトの時分割（自動尺） | 〃 |
| `fade` | `view` の代わり＝**フェード**：黒への溶暗→切替→溶明（道中の絵を見せないカット）。`travel`＝溶暗/溶明それぞれの尺（既定1.2秒） | 〃 |
| `via` | **通過点**（連続ドリー・§3）。視点行の間に挟む | 〃 |
| `travel` | **その点に到達するまで**の区間尺[秒]＝via 行・via 連続の着点行／via 無し行では glide/fade の遷移尺 | 自動 |
| `hold` | 到達後の静止[秒]（着地から計時） | 台本既定 → 3 |
| `title` | シーン名（**既定で見せたい言語をそのまま書く**） | — |
| `<lang>` | 他言語の兄弟（`en:`/`jp:`…）＝視聴者の `?lang=` と一致すればそちら | — |
| `caption` | 字幕の明示上書き（無ければ `scene[lang] ?? title` を代用表示） | — |
| `pre` / `slide` / `mobile` | 入場の見せ玉 / 紙カード(画像URL・生テキスト) / 縦画面Δz | — |

- **先頭行** ＝ `view`/`glide` の視点行にする（その視点で即開始＝jump・遠景の弧を作らない）。**末尾** ＝ finale（遠景）を足さない。＝「定義したそのまま」。
- via 無し行の `travel` は意味を持たない（fly/glide の尺は自動）。

## 3. via（連続ドリー）
```jsonc
{ "title": "河口", "jp": "隅田川・河口", "view": "#17.61/…/l=terrain", "hold": 1 },
{ "via": "#17.62/…", "travel": 4 },     // 通過点＝停止しない・シーンに数えない（歩数・目次に出ない）
{ "via": "#17.47/…", "travel": 8 },     // ランドマーク前はゆっくり＝区間ごとに緩急が書ける
{ "title": "スカイツリー", "view": "#16.47/…", "travel": 5, "hold": 4 }   // 着点行の travel＝最終区間
```
- 直前の着点から次の `view`/`glide` 着点まで **1本の centripetal Catmull-Rom** で貫く（5自由度：経緯度=曲線／zoom/pitch/bearing=区間補間・全体に ease in/out・通過保証）。
- `travel` 省略区間は経路長比例の自動尺。**道中はカメラのみ**＝`l=`/`c=` は直前シーンで設定しておく。
- 道中の字幕＝**着点行**の字幕を出しっぱなし（川を遡る間ずっと見出しが乗る）。
- 掴めば中断＝主導権は人（flyTo/glideTo と同じ手綱）。

## 4. 字幕の言語（title に書いた言語が既定）
**台本側に言語指定は無い**：既定で見せたい言語を `title` にそのまま書く。他言語は同じ行に言語コードの兄弟（`en:"…"` / `jp:"…"`）を足し、**選ぶのは視聴者の `?lang=`**（解決＝ `scene[lang] ?? title`。`caption` はさらにその上書き）。
```jsonc
{ "title": "東京駅", "en": "Tokyo Station", "view": "#…" }   // 既定→東京駅／?lang=en→Tokyo Station
```

## 5. waitLoading / preload（任意）
- `waitLoading:true` ＝ **プリロード前提**：全行の視点（via 込み）の重いデータ（3D都市）を**読み切り、都市を GPU へ立て切ってから開幕**する。リビールは最初のフレームから本物の3D（基図の押し出し箱を見せない）・道中も後続シーンも点灯だけで即立つ。**タイムアウトで妥協しない**（失敗した区だけ諦めて進む＝黒画面で止まりはしない）。
- `preload:[…]` ＝ 明示の先読みリスト（カタログ名・この順に焼く）。無指定＝視点から自動導出。**台本の持ち物**＝載せ替え時に持ち越さない。
- **preload 明示＝上映中の関所**（2026-08-21）：上映中（▶・drop・`?scene=` とも）はリスト**外**の区の自動ロードを一切始めない（fast復帰もさせない）。フライトの経由地・画面端に掛かった無関係区（例＝新宿シーンの世田谷）を観客の自機が拾って急に重くなる件の根治＝**台本作者がロード対象を完全に決める**。リストに無い区は基図の押し出し箱のまま＝載せたい区は preload に書く。無指定（視点導出）の台本は従来どおり絞らない。終演で自然解除（通常閲覧には影響なし）。

## 5b. 開幕の作法（ドロップ / ?scene= の再生）
- **黒からの fade-in**：再生は必ず黒幕で始まり、開始と同時に約1.2秒で溶明＝先頭視点への jump・読み込み・基図タイルの立ち上がりは見せない。
- **進捗パネルは実際に読むものがある時だけ**：温間（IDB 焼き済み・立ち上げ一瞬）なら何も出さず黒幕→即開幕。実読みの兆候（建物のネットワーク進捗・標高タイル読込・0.7秒を超える立ち上げ）が観測された時だけ中央パネルが現れる。
- **パネルは「何をどう読んでいるか」を出す**：読み込み中の区名と枚数（`墨田区 12/47枚`・カタログ走査）＋標高タイル、区の歩み `N / M 区`、バーは区の歩み＋読みかけ区のタイル進捗でなめらかに進む。読み切った後の最終段は「都市を立ち上げ中…」（IDB→GPU 常駐）。
- **終幕＝括弧を閉じる**：最終シーンの hold を終えたら、黒への溶暗（約1.2秒）を挟んで**ドロップした画面**（l=/c= 込みの当時の共有URL）へ帰り、溶明する＝始まった所で終わる。読み込み失敗などの fallback も同じ着地＝どの経路でも黒幕を残さず元の画面へ。
- **上映中はドロップ禁止（無視）**：▶デモ・シーン再生の上映中（準備〜走破〜終幕括弧）に落とされたファイルは台本も GIS も受けない（トースト「上映中はドロップ無効」だけ出す）。

## 6. 再生の作法・二つのプロファイル
- **ドロップ / `?scene=`** ＝ **PC 前提・綺麗な動画が撮れることが最優先**（モバイルは考慮しない）：`type` 判定→demo プレーヤーの**素モード**で自動上演（バー無し・実秒クロック・プリロード完遂ゲート・via の緩急が効く）。先頭 jump・末尾 finale なし。画面収録すれば動画になる（本質は配って各自の GPU で再生）。音は付けない＝**画面収録後に編集ソフト（iMovie 等）で**。
- **▶（組み込みデモ）** ＝ **絶対に失敗しない**側：非力な端末でも動く前提＝操縦バー・目次・クリッカー対応・裏読み＋序盤の構成で時間を稼ぐ（待たずに始め、間に合わない物は後から立つ）。台本は demo/scenes.js（JS モジュール＝svg を vite にバンドルさせるため）だが、**行の書式はこの仕様と同一**＝via ドリーも書ける。

## 7. プレーヤー API（アプリ向け・エディタの土台）
- **`map.playScenes(obj, opts?)`** ＝ 台本オブジェクトを直接上映する第三の入口（drop / `?scene=` も同じ道）。上映中は `false` で受けない（先に stop）。
  - `from`＝開始行／`quick:true`＝軽い試写（黒幕・waitLoading ゲート・終幕括弧なし＝エディタの行プレビュー用）
  - `onScene(i, scene)`＝行の上映開始（フライト開始前＝行ハイライト用）／`onEnd(reason)`＝どの終わり方でも1発（`"finished"`=走破・`"stopped"`=中断）
- **`map.stopScenes()`** ＝ 停止。上映中でも準備中（黒幕＋読み込み待ち）でも安全＝黒幕・パネル・上映ロックを残さない。現在地に留まる（括弧は走破だけの儀式）。
- **`parseScenes(obj, issues?)` / `compileVias(rows, issues?)`**（demo/scene-adapter.js・純関数）＝ `issues` 配列を渡すと `{row, code, msg}` の診断を返し console.warn しない（code＝`empty-row` / `leading-via` / `orphan-via`・row＝0起点）＝エディタの行内エラー表示用。
- **プレーヤーの器**＝demo ガジェット。`map.gadget.demo({ player: true })` ＝ 組み込み台本なしの素のプレーヤー搭載（▶を出さない）＝エディタは playScenes が台本を持ち込む。
- **エディタ**＝`/japan/scene.html`（芯は demo/editor.js・PC専用・`?lang=en` で UI 英語）。**ドロップ**＝舞台/パネルへ .scenes(.gz) を落とすと再生でなく編集へ開く（このページは dropFile ガジェット非搭載）。**undo**＝スナップショット式（撮影/通過点/削除/全消去/読込/並べ替え/遷移切替が ⌘Z で戻る・パネルの ↶ も同じ）＝確認ダイアログは置かない。**キー**＝⌘Z undo／Delete=選択行の削除／Space=ここから試写（入力中は譲る）。**☁ クラウド**＝ログイン（GitHub/Google）した本人の置き場（account Worker `/me/files`・geoedit の geopbf と同じ器）へ `.scenes` を保存/開く。一覧は `.scenes` だけ（置き場は1つ・種類はエディタ毎）。公開台帳は地図作品用のまま（台本の共有は `?scene=` の URL を直接配る）。流れ＝**定義**（画角フレーム＝z と画面サイズの独立を活かし枠を先に決める）→**撮影**（📷撮影=permalink・◇通過点・⠿並べ替え）→**編集**（保持/遷移セレクタ=地図遷移・直線移動・フェード／行内診断／行クリック=その視点へ／試写=ここから・🎬上映）→**出力**（.scenes 書き出し・下書きは localStorage 自動保存）。出典（#attr）は画角の外＝パネル最下部。**カメラ実位置チップ**＝画角フレームの**外・上方の帯**（緯度経度・高度・方位・視野H°×V°＝`map.view.eye`＝透視カメラそのものの位置と画角・参考値）。**上映/録画時の確認用＝録画クロップには写らない**。視野=垂直50°(エンジン既定)×水平はフレームのアスペクト依存（16:9で79°）。チルトは各行の permalink（`75t`）が持つ。`?lang=en` でラベル英語。
- **🎥 録画（動画ファイル直出力）**＝画角フレームを Region Capture でタブから切り出し、MediaRecorder の **MP4/H.264** で直接ファイル化（iMovie 等へそのまま・依存ゼロ・非対応環境のみ .webm）。字幕・黒フェード等の DOM 演出も忠実。画質＝録画中は動的解像度を固定（`map.pinRes`）＋フレームを目標解像度（16:9=1920×1080 等・CSS×dpr・舞台に内接クランプ）へ一時リサイズ＋高ビットレート（≈0.2bit/px/frame）。頭とケツ＝上映の儀式そのまま（黒 in／終幕の黒で out）。初回に「このタブを共有」の許可が1回要る（Chrome の作法）。
- **`map.sceneTimeline(obj)`** ＝ **タイムライン（時刻評価・スクラブ）**：再生せず任意秒の絵を出す → `{dur(総尺・秒), rows(行の区間 t0/tArrive/t1・◇の実到達 knots[]), at(秒)＝純評価, seek(秒)＝画面へ（カメラ直書き＋その行までの l=/c= 累積適用＋fade の黒 cover）, end()＝スクラブ終了（URL書込は1回）}`。芯＝**flight の時刻評価プラン**（`flyPlan / glidePlan / glidePathPlan`・ortho-core＝ライブ飛行も同じプランを rAF でなぞる＝数式は一箇所）×プレーヤー規則の写し（demo/scene-timeline.js・純関数）。slide の幕は時間だけ数える（DOM演出は再現しない）。上映中は受けない（先に `stopScenes`）。
- **エディタのスクラブバー**＝舞台下端の帯：行ごとの遷移(青)/保持(白)・◇通過点＝黄の刻み（緩急がそのまま見える）・総尺常時表示（作品の長さの読み）。ドラッグ＝時刻評価（上映は止まる）・行ハイライト追随・離すと URL 確定。**上映中は再生ヘッドが追随**（表示のみ・絵は本物の再生が描く＝行頭 `onScene` で実時間クロックを t0 へ再同期し行の終端 t1 で待機＝読み待ち等の揺らぎは次の行頭で吸収。遷移尺はプラン共有ゆえ道中はほぼ実尺どおり）。
