# sokutei ＝ 鳥獣の体長・体重 測定（PWA）

捕獲した鳥獣の写真から体長を測り、体重を推定して記録するアプリ。www.ortho-earth.com/sokutei/（www の一覧には載せない単独の頁）。
iOS・Android の両方で同じコード（ブラウザで動く PWA＝ホーム画面に追加すればアプリとして・網なしでも開く）。サーバー無し＝記録と写真は端末の中（IndexedDB）だけ。

## 使い方（現場）

1. 個体の横（同じ地面）に **A4 用紙**（基準物）を置き、真横〜斜め上から 1 枚撮る。
2. 写真の上で、用紙の 4 隅を **長い辺の端から順に** タップ（①→②が長辺）。斜めから撮った遠近はこの 4 隅から補正する。
3. 鼻先 と 尾の付け根 をタップ → 体長（cm）と推定体重（kg）が出る。体が曲がっていれば背中線の途中もタップ（折れ線の和）。点はドラッグで直せる（拡大鏡付き）。
4. 任意：胸囲（メジャー）・性別・成幼・実測体重（量った時）・メモ・現在地。保存。
5. 記録 → CSV 書き出し（共有シート／ダウンロード）。列は捕獲データ（csv/列の説明.csv）の語に寄せてある。

A4 の代わりに A3・B4・任意の縦横、または「既知の長さの 2 点」（メジャーの両端）も選べる。2 点方式は真上から撮った時だけ正しい（4 隅方式を推奨）。

## 体重の式（暫定）

- 体長だけ：W = k × L³（L cm → W kg）。k はイノシシ 3.3e-5・シカ 2.3e-5（他社アプリの推定値の中央値から逆算した仮の値）。
- 体長＋胸囲：W = L × G² ÷ c。c はイノシシ 14400・シカ 15000（家畜の経験式を元にした仮の値）。胸囲が入ると精度が大きく上がる。
- 実測体重を記録に入れていくと、設定の「係数を実測から出し直す」で k・c を自分の地域の実測に合わせられる（中央値＝外れ値に強い）。

## 構成

- `src/measure.js` 画素 → 実寸の算術（ホモグラフィ・折れ線）。DOM 無し。
- `src/weight.js` 換算と係数の再推定。DOM 無し。
- `src/store.js` IndexedDB の記録・localStorage の設定・CSV。
- `src/app.js` 画面（素の DOM）。pan/zoom/タップ/ドラッグは Pointer Events。
- `src/sw.js` サービスワーカーの雛形。`vite.config.js` がビルド時にアセット一覧と版を埋めて `dist/site/sokutei/sw.js` に書く。
- `public/` manifest とアイコン（`npm run icons -w sokutei` で SVG から PNG を作り直す）。

```
npm run dev -w sokutei      # http://localhost:5197/sokutei/
npm test -w sokutei         # node だけの検定（射影変換・換算・CSV）
npm run deploy -w sokutei   # vite build && wrangler deploy（Cloudflare の鍵は手元）
```
