# 市町村のデジタルツインの作り方（規模別の指針）

起案 2026-11-21。横浜・京都・福岡・札幌・旭川に続き、朝倉市（福岡県）・川場村・草津町（群馬県）を作って分かったことを、次の市町村を作る人のための指針にまとめる。
中身は共有モジュール `@ortho-earth/citytwin`（`packages/citytwin/`）で、市町村ごとの頁（`apps/<id>/`）は「設定・辞書・焼きの設定・検定」だけを持つ。

## 1. まず型を決める

市町村の規模ではなく、**暮らしに要る物が境界の中で揃うか**で型が決まる。人口と面積は目安にすぎない。

| 型 | 例 | 見分け方 | 区 | 立体の建物 | 生活圏の枠 |
| --- | --- | --- | --- | --- | --- |
| A 政令市 | 横浜・京都・福岡・札幌 | 行政区がある | 区を選ぶ＋「全市」 | PLATEAU（LOD1 常時・LOD2 は先読み） | 要らない |
| B 一般市 | 旭川・朝倉 | 区が無い。駅・警察の本署・消防署・大きな病院が市内にある | 無し（1 行だけ） | PLATEAU が有れば使う。無ければ地理院の基図の建物の押し出し | 要らない |
| C 町村 | 草津町・川場村 | 駅・警察の本署・消防署・大きな病院のどれかが境界の外にある | 無し（1 行だけ） | 同上（ほぼ地理院の基図） | **要る**（`lifeBox`） |

型 C の見分けは、国土数値情報を `--inspect` で引けばすぐ分かる。今回の 3 つの実数（国土数値情報から焼いた台帳）：

| | 朝倉市 | 草津町 | 川場村 | （参考）旭川市 |
| --- | --- | --- | --- | --- |
| 面積 | 約 247 km² | 約 50 km² | 約 85 km² | 約 748 km² |
| 境界の中の駅 | 甘木ほか（甘木鉄道・西鉄） | 無し（長野原草津口まで 9.5 km） | 無し（沼田まで 9.2 km） | 有り |
| 警察 | 朝倉警察署 | 長野原警察署の管内（本署は町外） | 沼田警察署の管内（村内は駐在所） | 2 署 |
| 消防 | 甘木・朝倉消防本部 | 吾妻広域 西部消防署（町内） | 利根沼田広域 中央消防署（村外） | 市の消防 |
| 大きな病院 | 市内に 5 | 町内と隣町に 2 | 村内 1・沼田市に 2 | 市内 |
| 用途地域 | 有り（26 面） | 有り（13 面） | **無し** | 有り（295 面） |
| 小／中学校区 | 11／6 | 1／1 | 1／1 | 51／26 |

## 2. 小さな町村は広域で扱うべきか（判断）

**結論：アプリの単位は市町村のまま。台帳だけを生活圏まで広げる。** 広域で 1 本にまとめるのは、圏域から頼まれた時の選択肢として残す。

理由：

1. 見る人が探すのは「自分の町・村」。名所めぐり・歴史・統計・避難所・ハザードは市町村の単位で意味を持つ（川場の田園プラザ、草津の湯畑）。広域 1 本にすると、小さな町村は沼田市や吾妻郡の中に埋もれる。
2. 逆に境界で切ると、暮らしの答えが出ない。川場村で「最寄りの駅・救急の病院・管轄の警察署」を境界の中だけで探すと、駅 0・消防署 0・本署 0 になる。これが小さな町村の本当の問題で、広域化したい理由の中身はこれだけ。
3. そこで `lifeBox`（生活圏の枠）を足した。境界の外でも、最寄りの駅と線・管轄の本署・受け持ちの消防署・`majorHospitals` に挙げた病院は台帳に入る。「わが家のまわり」は村の外の沼田駅や利根中央病院を答える。徒歩の網の外になる遠い駅は「約 9 km」と直線で出す（歩く道順は出さない）。
4. 軽さでも単独が有利。台帳は川場 0.2 MB・草津 0.15 MB（旭川 5 MB）。広域にすると歩ける道の網と基図の保存が面積に比例して増え、オフライン保存が重くなる。
5. 広域 1 本が向くのは、圏域そのものが主語の時（利根沼田広域・吾妻郡・定住自立圏など）。その時は型 A の仕組みをそのまま使える（市町村を「区」として並べ、「全域」を足す）。新しい仕組みは要らない。

目安：

- 単独で作る … 名所が 5 つ以上、歴史の章が 4 つ以上書ける（川場 7・5、草津 9・7）。
- 広域を考える … 名所や歴史が 2〜3 しか書けない、または見る人の主語が圏域（郡・広域連合・観光圏）。
- どちらでも … 型 C の `lifeBox` は必ず引く。

## 3. データの出どころ

| 台帳 | 出どころ | 取れる場所 | 小さな町村での注意 |
| --- | --- | --- | --- |
| 境界・鉄道・バス停・公共施設・用途地域・学校区・警察／消防の管轄 | 国土数値情報（N03・N02・P11・P05 ほか・A29・A27・A32・P18・P17） | クラウドでも可 | 用途地域が無い村は `skip: ["zoning"]` と `noAreas: ["zoning"]`。0 件の区分は `allowEmpty` |
| 立体の建物 | PLATEAU の目録（`api.plateauview.mlit.go.jp/datacatalog/plateau-datasets`）を市区町村コードで引く | クラウドでも可 | 無ければ `BLD_SETS: []`＝地理院の基図の建物を押し出す（旭川と同じ）。UI に PLATEAU の字は出さない |
| 名所の写真・駅の Wikipedia | Wikipedia／Wikimedia Commons | Mac だけ | 記事の無い名所は写真なしで出る |
| 歩ける道の網 | OpenStreetMap（Overpass。混んでいたら Geofabrik の県の PBF を `ogr2ogr` で） | Mac だけ | `lifeBox` ではなく境界の中だけ |
| 施設の英語名・住所 | 郵便番号データ＋ kuromoji ＋ OSM の `name:en` | Mac だけ | 郡の名は `gun` で外す |
| 人口の統計 | e-Stat（国勢調査 小地域・年齢別） | Mac だけ | 町丁目の下限を `min.small` で下げる |
| 避難所・ハザード | 既存の県の台帳（`hinan/<県>.json`）・国のハザードのタイル | 既存 | 洪水と土砂が基本。津波・高潮は海のある所だけ |

## 4. 型ごとの設定の違い

| | A 政令市 | B 一般市 | C 町村 |
| --- | --- | --- | --- |
| `WARDS` | 区の数だけ | 1 行（市全体） | 1 行（町村全体） |
| 交通の既定 | 地下鉄 | 駅・バス | 駅（町村の外）・バス |
| 区域の層 | 用途地域・小／中学校区 | 同じ | 用途地域は有る時だけ |
| 急病の案内 | 夜間急病センター＋ #7119 | 確かめられた物だけ | 公式に確かめられない時は出さない |
| 歴史の章 | 6〜8 | 6〜8 | 5〜7 |
| `BAKE` の追加 | `subwayOp`・`fitBox` | 無し | `gun`・`lifeBox`・`policeNames`・`allowEmpty`・`dropNames`・`min.small` |
| オフライン保存の目安 | 450〜550 MB | 100〜180 MB | 100 MB 未満 |

オフライン保存の大きさは、Mac で本番と同じ build を配信して実測し、`OFFLINE_MB` に書く（見積もりのまま出さない）。

## 5. 手順

1. **調べる**（クラウドで可）：市区町村コード・PLATEAU の有無・`bake-<id>.mjs --inspect` で国土数値情報の中身。ここで型が決まる。
2. **器を起こす**：`node packages/citytwin/scripts/new-city.mjs <id> "<English>" <日本語の名> --port=52xx`（型紙は旭川）。
3. **書く**（市町村ごとに手で）：
   - `apps/<id>/data.ts` … 範囲・名所・歴史の章・めぐる順・病院・ハザード。座標と年は Wikipedia と公式の頁で確かめる。
   - `apps/<id>/scripts/bake-<id>.mjs` … 焼きの設定（型 C は `lifeBox` ほか）。
   - `apps/<id>/i18n/pages/<id>.json` … 辞書（英語が鍵・25 言語）。`npm run i18n:build -w <id>`。
   - `apps/<id>/tests/t-<id>.mjs` … 設定の検定。
4. **登録する**：`scripts/deploy-engine.mjs` の APPS・`scripts/deps-map.mjs`・`scripts/test-all.mjs`・`packages/citytwin/tests/t-core.mjs` の ALL・`npm install`。
5. **焼く**：国土数値情報の分はクラウドで、残り（`photos,walk,en,places,stawiki,census`）は Mac で。出力は `ortho-data/japan/<id>/`。
6. **確かめる**（Mac・GPU）：390px を先に。名所めぐり・わが家のまわり（型 C は村の外の駅と病院が出るか）・ハザード・英語の表示・オフライン保存の実測・`og.jpg` の差し替え。
7. **出す**：PR → main で自動配信（Worker `ortho-<id>`・`/<id>/`）。www のカードは頼まれた時だけ。

## 6. 守ること

- エンジンは共有（`sharedEngine()`）。頁がエンジンの持つライブラリを自分で抱えない。
- 既存の市の台帳を変えない。共有の焼きに足す仕組みは「設定が無ければ今まで通り」にする（今回の町村の仕組みは旭川の台帳がバイト単位で同じことを確かめた）。
- 26 言語。辞書の鍵は英語、数字は算用数字。
- 確かめられない事実（急病の窓口・開設年）は書かない。
- 警察・消防の管轄（国土数値情報 P17・P18）は非商用の許諾。台帳に `lic` を付けたまま使う。
