# Contributing to Ortho Earth

[日本語は下にあります](#日本語)

Ortho Earth is built and maintained by one person. Bug reports, ideas and pull requests are all welcome.

## Questions and ideas

- **Bugs**: open an [issue](https://github.com/kenjiyoshidahome2026-bit/ortho-earth/issues/new/choose).
  The browser, OS and GPU matter a lot for a WebGPU renderer; [www.ortho-earth.com/check/](https://www.ortho-earth.com/check/) shows them in one place, please paste what it says.
- **Questions, ideas, "is it possible to…"**: use [Discussions](https://github.com/kenjiyoshidahome2026-bit/ortho-earth/discussions).
- **Security problems**: never in public. See [SECURITY.md](SECURITY.md).

## Pull requests

- Small fixes (typos, docs, an obvious bug) can go straight to a pull request.
- For anything bigger (a new feature, a new layer type, changes to the renderer or the data formats), please open an issue or discussion first,
  so we can agree on the direction before you spend time on it.
- Run `npm test` at the root before you push. [docs/development.md](docs/development.md) explains setup, the browser suites and the rest.
- Keep one topic per pull request.

## Contributor License Agreement

Ortho Earth is open source (GPL-3.0-or-later, MIT and CC BY-SA 4.0, see the [README](README.md#license))
and is also offered under a commercial license. To keep that possible, every contributor signs the [CLA](CLA.md) once.
You keep the copyright to your work, and your contribution always stays available under the open-source license.

On your first pull request a bot will ask you to sign by replying with one sentence. That's it.

## Code of Conduct

Be kind. This project follows the [Contributor Covenant](CODE_OF_CONDUCT.md).
