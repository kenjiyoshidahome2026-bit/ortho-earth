# 全国の市区町村の台帳（デジタルツインを全国へ広げる前の下調べ）

`municipalities.tsv` は、デジタルツイン（`@ortho-earth/citytwin`）を次の市町村へ広げる時に要る市町村ごとの事実を、全国分まとめて先に集めた物。
**鍵は 5 桁の全国地方公共団体コード**（チェックディジット無し＝国土数値情報 N03_007・PLATEAU の `city_code` と同じ）。同じ名の市町村（府中市 東京・府中市 広島・府中町 広島、草津町 群馬・草津市 滋賀 など）は名でなくコードで分ける。

- 組み直し：`node packages/citytwin/scripts/build-ledger.mjs`（クラウドで可・約 45 秒＋初回の取得 1.5 GB・生の zip は `scripts/.cache/ledger/`）
- 行：現行の市区町村 1,747（市 792＝うち政令市 20・特別区 23・町 743・村 189＝北方領土の 6 村を含む）＋ 政令市の区 171（浜松は 2024-01-01 の 3 区）＝ 1,918 行
- 文字コード UTF-8・タブ区切り・1 行目が列名。Numbers／Excel でそのまま開ける

## 出典・許諾

- 国土数値情報 行政区域（N03-2025）・鉄道（N02-25）・医療機関（P04-20）・用途地域（A29-19）・小学校区（A27-21）・中学校区（A32-21）・消防署（P17-12）・警察署（P18-12）国土交通省。P17・P18 は非商用の許諾（台帳には署の名と数だけを写す）。
- 3D 都市モデル（Project PLATEAU）の配信目録 国土交通省。
- 令和 7 年国勢調査 総務省統計局（加工）。
- 全国地方公共団体コード 総務省。
