# quiet-mono

The design kit behind the ortho-earth map apps: SCSS tokens and the quiet, monochrome manners of the UI
parts that sit around a map (docks, chips, toasts, panels). The data belongs to each app; the face is here.

```
npm i quiet-mono
```

```scss
@use "quiet-mono/tokens.scss";
@use "quiet-mono/components.scss";
```
