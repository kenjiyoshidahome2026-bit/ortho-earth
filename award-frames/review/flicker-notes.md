# 冒頭の海面のちらつき — 調べた結果（本番 /yokohama/・MacBook の GPU・2026-05-20）

冒頭と同じ構図で、5 通りの条件を 12 コマずつ撮り、水面を含む切り抜き（中央部・600×300）で、隣り合うコマの平均差を測りました。

| 条件 | 隣のコマとの差（平均） | 見た目 |
|---|---|---|
| 1 影あり・太陽動く・カメラ動く（動画と同じ） | 9.0 | 水面にざらざらの斑点。コマごとに模様が変わる＝ちらつく |
| 2 影あり・太陽固定（12時）・カメラ止める | 0.1 | 斑点はあるが止まっている |
| 3 影あり・太陽固定・カメラ動く | 11.2 | 斑点がコマごとに変わる＝ちらつく |
| 4 影あり・太陽動く・カメラ止める | 0.2 | 斑点は止まったまま（影だけが動く） |
| 5 影なし・カメラ動く | 6.6（建物が動く分だけ） | 水面はなめらか。斑点なし |

※ 3 と 5 の差の数字には、カメラが動いて建物がずれる分も入っています。斑点の有無は画像（flicker-cases.jpg）で確認。

**原因**：建物の影を落とすと、平らな海面（と広場などの平らな地面）に細かい斑点（影の「にきび」＝自分自身への影の誤判定）が出ます。この斑点はカメラが動くたびに模様が変わるので、こま撮りで回すとちらつきになります。太陽が動くこと自体は原因ではありません（条件 4）。影を消すと出ません（条件 5）。

**動画での直し方（アプリには触れない）**：カメラを止めて、太陽だけを動かす（条件 4）。影が時間とともに回る様子はそのまま見せられ、ちらつきは出ません。
